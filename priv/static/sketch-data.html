How to Use Modes

👋 Welcome! Modes help you visualize your data in different ways. Each mode arranges nodes using specific rules, while Freeform views let you create custom layouts.

📊
Layout Modes

XY Mode: Shows nodes in their original positions with axes hidden. Great for seeing the base layout.

Date Mode: Arranges nodes along a timeline (X-axis) with categories as horizontal bands.

Timeline Mode: Shows time vs. value relationships with nodes positioned on both axes.

Value Mode: Groups nodes by value (X-axis) within category bands (Y-axis).

Category Mode: Creates columns for each category, ranked by position within the group.

Grid Mode: Arranges all nodes in a neat grid pattern based on their ID order.

Groups Mode: Clusters nodes around their group centers with optional physics simulation.

✏️
Freeform Views

Creating Views: Click "Save View → Freeform" to capture current positions and enable drag-and-drop editing.

Loading Views: Select any saved view to restore those positions and continue editing.

Drag Rules: You can only drag nodes in Freeform views. Other modes show a helpful hint when you try to drag.

🎯
Interaction Tips

Selection: Hold Shift for lasso select, Alt for box select.

Groups: Create groups to see convex hulls and enable group-based clustering and connections.

Edges: Enable edges when grouping is active to see connections between nearby nodes within each group.

🚀 Ready to explore? Try switching between different modes using the dropdown at the top to see how your data looks!
